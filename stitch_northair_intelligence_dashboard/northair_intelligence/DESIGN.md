## Brand & Style

This design system embodies high-precision environmental analytics, atmospheric telemetry, and enterprise climate intelligence. It marries the typographic rigor of Linear, the compositional clarity of Vercel, the refined tactility of Stripe, and the restrained finish of Apple.

The aesthetic fuses **Modern Technical Minimalism** with **Atmospheric Precision**:
- **Target Audience:** Climate scientists, enterprise sustainability executives, industrial facility operators, and regulatory auditors who demand institutional trust, rapid metric comprehension, and zero visual fatigue over prolonged sessions.
- **Emotional Resonance:** Authoritative, scientifically exact, pristine, calm, and forward-looking. The interface should feel as pure and calibrated as an optical particle counter in an alpine cleanroom.
- **Visual Grammar:** Pristine white telemetry surfaces elevated on warm limestone canvas, structured hairline boundaries, precise tabular alignment, and an unambiguous clinical severity semantic scale.

## Colors

The palette operates under a dedicated Light Theme architecture calibrated for prolonged data auditing, high optical clarity, and strict contrast accessibility.

### Foundational Canvas & Text
- **Canvas Root:** `#FAFAF8` (Clean, warm soft off-white providing atmospheric lift without screen glare).
- **Surface Layer (Cards, Modals, Menus):** `#FFFFFF` (Pure optic white for discrete instrumentation pods).
- **Surface Inset / Subtle Tracks:** `#F3F5F3` (Muted slate-tinted white for metric rails, table headers, and sunken telemetry blocks).
- **Border / Hairline Dividers:** `#E9EDE9` (Subtle low-contrast mechanical stroke providing distinct structure without noise).
- **Text Primary:** `#202521` (Deep slate charcoal with a mineral tint, avoiding harsh absolute black while preserving WCAG AAA legibility).
- **Text Secondary / Metadata:** `#737B75` (Calibrated forest-neutral gray for parameter units, timestamps, and secondary descriptors).
- **Text Inactive / Tertiary:** `#9DA6A0` (Restrained muted tone for empty states and subtle ticks).

### Brand & Interactive Accents
- **Primary Accent:** `#286B4E` (Forest Emerald; reserved for deliberate calls to action, committed states, active tab strokes, and primary key indicators).
- **Secondary Accent Surface:** `#EAF3ED` (Soft Sage; utilized for active selection fills, low-intensity badge backgrounds, and primary hover fills).
- **Interactive Focus Ring:** `#286B4E` at 20% opacity (`rgba(40, 107, 78, 0.20)`), layered over an internal `1px` white offset ring.

### Pollution Severity Scale (Sensor Standards)
A strictly codified six-tier chromatic gradient representing environmental risk levels according to international atmospheric air quality indices:
1. **Good:** `#26966B` (Pristine air quality; nominal baseline; background tint: `rgba(38, 150, 107, 0.08)`).
2. **Satisfactory:** `#8EBB56` (Acceptable sensor range; background tint: `rgba(142, 187, 86, 0.10)`).
3. **Moderate:** `#E5B94F` (Cautionary advisory threshold; background tint: `rgba(229, 185, 79, 0.10)`).
4. **Poor:** `#E58B38` (Unhealthy for vulnerable populations; background tint: `rgba(229, 139, 56, 0.10)`).
5. **Very Poor:** `#D85D43` (Actionable hazard; background tint: `rgba(216, 93, 67, 0.10)`).
6. **Severe:** `#B93636` (Critical containment/evacuation alarm; background tint: `rgba(185, 54, 54, 0.12)`).

### Chart & Visual Telemetry
- **Chart Neutral:** `#87918A` (Grid lines, baseline thresholds, moving averages, and secondary time-series comparisons).
- **Chart Grid Stroke:** `rgba(135, 145, 138, 0.18)` on a 1px dashed configuration.

## Typography

The type hierarchy is engineered entirely around **Inter** with OpenType feature flags active: `cv02`, `cv03`, `cv04` (differentiating l, I, 1), `cv11` (single-storey a), and `tnum` (tabular lining figures) across all sensor streams, charts, coordinates, and reading cards.

### Typographic Principles
- **Tabular Precision (`tnum`):** All scientific metrics, AQI scores, particulate densities (PM2.5, PM10), parts-per-million (PPM) readings, and latitude/longitude coordinates must enforce `font-feature-settings: "tnum" 1`. This prevents visual jitter when streams update live via WebSockets.
- **Negative Tracking on Scale:** Negative letter-spacing is applied systematically to headlines and metric values above 18px to replicate the tight, engineered finish found in high-performance developer tools and operating systems.
- **Micro-Labels & Technical Captions:** Telemetry captions and table headers run at 11px uppercase with `+0.04em` tracking in weight `500`, utilizing `#737B75` for quiet clarity.

## Layout & Spacing

The layout model utilizes a multi-tier dashboard framework engineered for extreme data density without claustrophobia.

### Layout Philosophy & Rhythm
- **Fixed-Max Fluid Workstation:** Outer workspace spans a fluid container with a maximum constraints ceiling of `1680px`. Left rail and utility inspectors dock at fixed dimensions, allowing the primary data matrix to flex proportionally.
- **Grid Architecture:** 
  - **Desktop (1200px+):** 12-column layout; gutter `1.5rem` (`24px`); outer section margin `2.5rem` (`40px`).
  - **Tablet (768px - 1199px):** 8-column layout; gutter `1rem` (`16px`); outer margin `1.5rem` (`24px`). Collapsible navigation collapses into an icon dock.
  - **Mobile (<768px):** 4-column layout; gutter `0.75rem` (`12px`); outer margin `1rem` (`16px`). Multi-column telemetry cards wrap linearly into single-column modules.
- **Structural Density:**
  - Micro-spacing (`space-3xs` to `space-xs`): Reserved for badges, icon-to-metric offsets, and inline status indicator dots.
  - Component padding (`space-sm` to `space-base`): Default padding inside table cells, compact buttons, and metric modules.
  - Card internal padding: `space-xl` (`24px`) for primary visualization charts; `space-base` (`16px`) for high-frequency KPI widgets.

## Elevation & Depth

This system avoids heavy drop shadows, skeuomorphic shading, or stark borders, favoring **Crisp Hairline Boundaries and Apple-Calibrated Ambient Lighting**.

### Layering Architecture
Visual hierarchy is defined by physical stacking on the `#FAFAF8` substrate:

1. **Level 0 (Canvas Base):** Surface `#FAFAF8`. Flat plane with zero elevation.
2. **Level 1 (Telemetry Panels & Instrument Cards):** Pure White `#FFFFFF`. 
   - Border: `1px solid #E9EDE9`.
   - Shadow: `0 1px 2px 0 rgba(32, 37, 33, 0.03), 0 1px 3px 0 rgba(32, 37, 33, 0.02)`.
   - Result: Tactile sheet appearance with crisp physical delineation.
3. **Level 2 (Hovered Cards & Interactive Controls):** Pure White `#FFFFFF`.
   - Border: `1px solid #D6DCD7`.
   - Shadow: `0 4px 6px -1px rgba(32, 37, 33, 0.04), 0 2px 4px -2px rgba(32, 37, 33, 0.03)`.
4. **Level 3 (Flyouts, Menus & Filter Popovers):** Pure White `#FFFFFF`.
   - Border: `1px solid #E0E5E1`.
   - Shadow: `0 10px 15px -3px rgba(32, 37, 33, 0.05), 0 4px 6px -4px rgba(32, 37, 33, 0.03)`.
5. **Level 4 (Telemetry Drawers & Global Modals):** Pure White `#FFFFFF`.
   - Border: `1px solid #D6DCD7`.
   - Shadow: `0 20px 25px -5px rgba(32, 37, 33, 0.07), 0 8px 10px -6px rgba(32, 37, 33, 0.04)`.
   - Backdrop: `rgba(32, 37, 33, 0.35)` with `backdrop-filter: blur(4px)`.

### Hairline Rules
All borders must be rendered at true physical `1px` (or `0.5px` on high-DPI displays where supported via sub-pixel CSS). No gradient strokes or decorative neon glows are permitted.

## Shapes

The design uses an intentional, precision-engineered geometric radius (`Level 2: Rounded`). This strikes an exact balance between modern industrial hardware interfaces and polished web software.

### Corner Radius Allocation
- **Cards, Instrument Panels, Large Data Modules:** `8px` (`0.5rem`) via base shape token.
- **Buttons, Form Inputs, Filter Bars, Select Pickers:** `6px` (`0.375rem`) to maintain sharp, tool-like utility.
- **Status Badges, Severity Indicators, Sensor Tills:** Full pill radius (`9999px`) to create an immediate visual distinction between actionable operational controls and passive diagnostic labels.
- **Nested Inner Surfaces (e.g., chart canvases inside cards):** `6px` (`0.375rem`), adhering to the standard nested radius formula: $R_{inner} = R_{outer} - P$ where $P$ is padding.

## Components

### 1. Buttons
- **Primary Action:** Solid `#286B4E` background, `#FFFFFF` text, `font-weight: 500`. Shadow: `0 1px 2px rgba(40, 107, 78, 0.20)`. Hover: `#225841`. Active: `#1B4734`.
- **Secondary / Ghost Neutral:** `#FFFFFF` card surface, `1px solid #E9EDE9`, `#202521` text. Hover: `#FAFAF8` with border `#D6DCD7`.
- **Destructive:** `#FFFFFF` background, `1px solid rgba(216, 93, 67, 0.30)`, `#D85D43` text. Hover: `#D85D43` solid, `#FFFFFF` text.
- **Dimensions:** Default height `32px` (dense metric operations) and `36px` (global toolbar actions). Horizontal padding `12px` and `14px`.

### 2. Metric & Sensor Cards
- Container: `#FFFFFF`, `1px solid #E9EDE9`, `border-radius: 8px`, padding `16px`.
- Layout: 
  - Top: Parameter label (e.g., `PM2.5 DENSITY`) in `label-mono`, color `#737B75`, flex-aligned with a real-time heartbeat pulsing dot.
  - Middle: Primary reading in `metric-display`, followed immediately by unit descriptor (e.g., `µg/m³`) in `body-sm`, color `#737B75`.
  - Bottom: Delta indicator showing deviation over past 24h alongside a micro sparkline rendered with 1.5px stroke width.

### 3. Severity Chips & Badges
- Pill-shaped (`border-radius: 9999px`), height `20px`, padding `0 8px`, typography `label-mono`.
- Display syntax: A `6px` solid circle dot colored with the severity hex, followed by `2px` horizontal gap and the textual label in `#202521`.
- Background fill uses the dedicated 8–12% tinted alpha channels corresponding to the respective severity hex (e.g., Good: `rgba(38, 150, 107, 0.08)`).

### 4. Input Fields & Select Controls
- Surface: `#FFFFFF`, border: `1px solid #E9EDE9`, border radius `6px`.
- Sizing: Height `32px`, typography `body-md`. Placeholder color: `#9DA6A0`.
- Interaction: On focus, border transitions to `#286B4E` with box-shadow `0 0 0 3px rgba(40, 107, 78, 0.12)`.
- Numeric Inputs: Always formatted with right-aligned tabular figures (`tnum`).

### 5. Data Tables (High Density)
- Headers: Surface `#FAFAF8`, height `32px`, border-bottom `1px solid #E9EDE9`, typography `label-mono` in `#737B75`, text-align left (right for numeric sensor metrics).
- Rows: Surface `#FFFFFF`, height `36px`, border-bottom `1px solid #E9EDE9`. Row hover state: `#F3F5F3` flat fill.
- Padding: Cell padding `0 12px`.

### 6. Interactive Telemetry Charts
- Tooltip: Pure White `#FFFFFF`, `1px solid #D6DCD7`, shadow Level 2, radius `6px`, padding `8px 12px`.
- Axis Lines: None; horizontal reference grid lines use `1px dashed rgba(135, 145, 138, 0.20)`. Axis text uses `caption` in `#737B75`.
- Series Curves: Stroke width `2px`. Primary telemetry line uses `#286B4E` with a linear area gradient fading to `rgba(40, 107, 78, 0.00)` at the zero baseline.
